# presets

Presets do Media Encoder (`.epr`) usados por script. São criados pelo José no Media Encoder
(Preset → Criar preset) e salvos aqui com estes nomes:

| arquivo | para quê | configuração |
|---|---|---|
| `eve-cut-audio.epr` | exportar o áudio da sequência para a detecção de suspiros (P5, F2) | WAV, 48 kHz, 16 bits, mono |
| `eve-cut-legendas.epr` | tentar exportar as legendas em `.srt` por script (P1) | igual ao de cima + aba Legendas → "Criar arquivo sidecar", formato SubRip (.srt) |
